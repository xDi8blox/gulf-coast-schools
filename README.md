# Gulf Coast Schools: sample website

A one-page design proposal for **Gulf Coast International School (Gulf Coast Schools)**, 14 Niyi Ogunleye Street, Ojota, Lagos.

Live preview: https://xdiablo.xyz/gulf-coast-schools/

Sample by Diablo, [xdiablo.xyz](https://xdiablo.xyz). Not Gulf Coast Schools' official website.

- Plain HTML/CSS/JS, mobile-first, no build step.
- Photos and crest: the school's own images from its public school-directory listing.
- Text: the school's own Facebook descriptions, admissions and hiring posts, and its public directory listings. No fees, ratings, reviews or awards are shown.
- Admissions enquiry and job applications open WhatsApp with a message filled in; nothing is stored.
